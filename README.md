# One Minute to Midnight (working title)

First-person heist game in a 1929 art-deco manor. You get one minute. Every round, an echo of you replays what you did last time — so each attempt builds on the last until your crew of past selves pulls it off.

**Play:** see the Pages link in the repo sidebar (every push to `main` redeploys).

Controls: WASD + mouse (click to look), Shift run, E act, F punch, Q rewind. Phone: left thumb walks, right thumb looks, big button acts, ⟲ rewinds.

Dev: `npm run dev` · `npm test` · `npm run shots` (screenshots → `screenshots/`). See `CONTENT_PLAN.md`, `DECISIONS.md`, `CREDITS.md`.
