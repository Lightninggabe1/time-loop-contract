# Time-Loop Contract (working title)

First-person puzzle-action browser game: one New Year's Eve gala at an art-deco manor, on repeat.

**Play:** see the Pages link in the repo sidebar (every push to `main` redeploys).

Controls: WASD + mouse (click to look), Shift sprint, E interact, Q/F item, Tab intel board. Phone: left thumb walks, right thumb looks.

Dev: `npm run dev` · `npm test` · `npm run shots` (screenshots → `screenshots/`). See `PLAN.md`, `DECISIONS.md`, `CREDITS.md`.
